💡 Engineering Note on Algorithm Trade-offs:

No single algorithm is universally optimal. Preemptive algorithms such as SRTF reduce average waiting time by prioritizing shorter jobs, but incur higher context-switch overhead. Round Robin guarantees responsiveness and fairness for time-sharing systems, while FCFS maximizes throughput with minimal scheduling overhead.

Starvation & Aging Demonstration (Priority Scheduling)

An educational module explaining why low-priority processes can suffer from starvation (indefinite postponement) and how the aging technique solves it by gradually boosting priority over time.

Rule: Priority increases by 1 for every 3 units waited in ready queue

⚠️ Starvation Scenario

In standard Priority Scheduling, if high-priority processes continually arrive, low-priority processes may never be dispatched to the CPU.

Victim Process: P4 (Priority: 8 - Low Priority)
Compromising Stream: P1, P2, P3 (High Priorities 1, 2, 2)
Starvation Cause: Strict priority dispatch without aging gives CPU only to higher priority jobs.

🎯 Aging Solution

Aging gradually increments the effective priority of waiting processes as their wait time increases, ensuring they eventually reach top priority.

Original Priority: P4: Priority 8
Aging Formula: EffectivePriority = Max(1, Original - Floor(Wait / Interval))

Algorithm Descriptions & Standard Formulas

FCFS (First Come First Serve):

Processes are executed in order of arrival. Non-preemptive. Simple FIFO ordering.

SJF (Shortest Job First):

The arrived process with the shortest burst time is selected first. Non-preemptive.

SRTF (Shortest Remaining Time First):

The arrived process with the shortest remaining burst time is selected. Preemptive SJF.

Round Robin (RR):

Each process gets CPU time according to the time quantum. Preempted processes re-enter the rear of the ready queue.

Priority Non-Preemptive:

The available process with the highest priority (lowest numeric value) is selected and runs to completion.

Priority Preemptive:

A higher priority process arriving during execution immediately interrupts and preempts the running process.

Standard Operating Systems Formulas:
  • Turnaround Time (TAT) = Completion Time (CT) - Arrival Time (AT)
  • Waiting Time (WT) = Turnaround Time (TAT) - Burst Time (BT)
  • Response Time (RT) = Time of First Execution - Arrival Time (AT)
  • Average Waiting Time = (Σ WT) / N
  • Average Turnaround Time = (Σ TAT) / N
  • CPU Utilization = (Total Busy Time / Total Timeline) × 100%
